LangChain Agent

Positioning: LangChain is a strong Python ecosystem path for building agent workflows around models, tools, prompts, memory/state, retrievers, and execution graphs. This track is useful when the agent is closer to Python data tooling or rapid AI experimentation.

How A LangChain Agent Is Built

Define model -> Define tools -> Define system instructions / prompt -> Bind tools to the model -> Create agent executor or graph -> Invoke with user goal and context -> Agent selects tools and returns grounded output
Building BlockRole
ModelThe LLM used for reasoning and response composition.
ToolsCallable functions such as patient search, chart lookup, or MCP-backed data retrieval.
Prompt/instructionsDefines persona behavior, safety rules, and domain boundaries.
Executor/graphControls the loop: reason, call tool, inspect result, continue or answer.
