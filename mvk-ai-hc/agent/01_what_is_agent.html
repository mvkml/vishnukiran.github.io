What Is An Agent?

PlainAn agent is a goal-driven AI workflow. It does more than generate a single answer: it can decide what information it needs, choose an approved tool, call that tool, inspect the result, and continue until it can respond responsibly.
TechnicalAn agent combines a language model, instructions, tool definitions, context, orchestration logic, and safety boundaries. In Healthcare Co-Pilot Studio, agents should never become the source of healthcare truth; they use governed tools and APIs to retrieve facts.
