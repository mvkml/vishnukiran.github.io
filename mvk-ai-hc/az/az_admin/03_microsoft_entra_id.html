Microsoft Entra ID

Definition Microsoft Entra ID is Microsoft's cloud identity service. It was previously called Azure Active Directory, or Azure AD.

What It Manages

Microsoft Entra ID manages:
  • Users
  • Groups
  • Login/authentication
  • App registrations
  • Enterprise applications
  • Multi-factor authentication
  • Conditional Access
  • Roles and permissions
  • Access to Azure subscriptions and resources

Simple Way To Think About It

Microsoft Entra ID = who you are and what you can access
Azure Subscription = where Azure resources are billed and managed
Azure Portal = the website/UI where you manage everything

Example Flow

User logs in
|-- Authenticated by Microsoft Entra ID
    |-- Gets access to Azure Subscription
        |-- Can manage Resource Groups
            |-- Can manage Azure Resources

Tenant Meaning

When someone says tenant, they usually mean an Entra ID tenant, which is like your organization's identity container in Microsoft cloud.
