Overview

Plain Before any API or database schema was built, the very first work on this project was understanding the data itself — a synthetic patient dataset, explored locally with Spark.
ItemValue
Sourcehc_bigdata/
DatasetSynthea — 18 synthetic-patient CSV tables (patients, encounters, conditions, claims, allergies, medications, and more)
EngineApache Spark 3.5.5, run locally (local[*]), via PySpark in a dedicated Python 3.12 virtual environment
Project phaseSprint 1 — "Foundation & Data," ahead of the actual API build-out

This is deliberately the first thing built in the project's roadmap — profiling and understanding a real-shaped healthcare dataset before designing the SQL schema and APIs that would eventually serve it.
