Role and Persona Procedure

usp_GetLLMOptionByUserOrPersona

Resolves which LLM configuration should be used for a request. It can resolve by UserId, by PersonaTypeId, and optionally by ModelRole.

AreaDetails
Source filehc_data_source/hc_sql/procedures/usp_GetLLMOptionByUserOrPersona.sql
Main purposeConvert account role or persona into the active LLM option used by the MAPI layer.
Input parameters@UserId, @PersonaTypeId, @ModelRole
Main tablesUsers, Roles, PersonaMapper, PersonaType, LLMMapper, LLMOption
Role pathUsers.RoleId -> Roles.RoleId -> PersonaMapper.RoleId -> PersonaType.TypeId

Sample Call

EXEC dbo.usp_GetLLMOptionByUserOrPersona
    @UserId = 1,
    @PersonaTypeId = NULL,
    @ModelRole = N'Executor';

Readable Join Version

SELECT
    u.UserId,
    u.Email,
    r.RoleName,
    pt.Name AS PersonaName,
    lm.ModelRole,
    lo.Provider,
    lo.Model,
    lo.Name AS LLMOptionName
FROM dbo.Users u
INNER JOIN dbo.Roles r ON r.RoleId = u.RoleId
INNER JOIN dbo.PersonaMapper pm
    ON pm.RoleId = r.RoleId
    AND pm.IsDefault = 1
    AND pm.IsActive = 1
INNER JOIN dbo.PersonaType pt ON pt.TypeId = pm.PersonaTypeId
INNER JOIN dbo.LLMMapper lm
    ON lm.PersonaTypeId = pt.TypeId
    AND lm.IsActive = 1
INNER JOIN dbo.LLMOption lo
    ON lo.LLMOptionId = lm.LLMOptionId
    AND lo.IsActive = 1
ORDER BY u.UserId, lm.ModelRole;
