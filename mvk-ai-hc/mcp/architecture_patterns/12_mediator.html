Mediator

GoF Behavioral PatternCurrent Concept
Plain: A Mediator coordinates interactions so components do not need to talk directly to each other.

What It Is

Mediator is a classic Gang of Four behavioral pattern. It centralizes coordination among objects or services that would otherwise become tightly coupled.

Why, When, How

Use it when many participants need orchestration but should not know each other's internal details.

Why We Chose It Here

Semantic Kernel plays a mediator-like role. It coordinates model instructions, plugins, tool calls, MCP clients, and final response composition without letting tools call each other directly.

Diagram

User request -> Semantic Kernel -> Model reasoning -> Approved MCP tool call -> Grounded response
Status: the Kernel coordination concept exists; multi-host mediation is future work.
