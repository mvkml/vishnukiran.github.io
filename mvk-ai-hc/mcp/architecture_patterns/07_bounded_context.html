Bounded Context

DDD Strategic PatternADR004 Core
Plain: A Bounded Context defines where a domain language and model are valid.

What It Is

Bounded Context is a core Domain-Driven Design pattern from Eric Evans' DDD work. It prevents one model from pretending to mean the same thing everywhere.

Why, When, How

Use it when different parts of a business use different rules, terms, workflows, data ownership, or security boundaries.

Why We Chose It Here

ADR004 treats OP, ICU, and Emergency as future patient subdomains that may deserve separate MCP hosts. This is the main architectural reason for host-boundary segregation.
