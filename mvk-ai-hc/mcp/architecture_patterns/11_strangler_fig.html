Strangler Fig

Migration PatternPlanned
Plain: Strangler Fig migration replaces an old structure gradually, one slice at a time.

What It Is

The Strangler Fig pattern, commonly associated with Martin Fowler's migration writing, describes incrementally replacing a system while it keeps running.

Why, When, How

Use it when a big rewrite would be risky, expensive, or disruptive.

Why We Chose It Here

Today's MCP host does not need an immediate split because only one tool exists. When more domains arrive, the team can extract one host at a time instead of rewriting everything.
