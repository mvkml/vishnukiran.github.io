Adapter

GoF Structural PatternPlanned
Plain: An Adapter lets one component work with another component that has a different contract.

What It Is

Adapter is a classic Gang of Four structural pattern. It wraps an incompatible interface and exposes the shape the caller expects.

Why, When, How

Use it when systems evolve separately, use different naming, or return different response structures but must participate in one workflow.

Why We Chose It Here

If OP, ICU, and Emergency MCP hosts develop different tool contracts, adapters can normalize them before the Kernel or gateway consumes them.
