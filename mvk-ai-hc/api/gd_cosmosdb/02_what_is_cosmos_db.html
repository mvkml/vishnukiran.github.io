What is Azure Cosmos DB

Plain Azure Cosmos DB is Microsoft's fully-managed database service built to do two things most databases have to trade off against each other: stay fast and available no matter how much traffic hits it or how many regions it's spread across, and let the shape of the data change without a migration every time.
CharacteristicWhat it means
Multi-modelThe same underlying service can be accessed through several APIs — document (NoSQL/Core), MongoDB-compatible, Cassandra-compatible, Gremlin (graph), Table, and PostgreSQL — so teams coming from different database backgrounds can use a familiar query style
Globally distributedA database can be replicated across any number of Azure regions with a couple of clicks, with Microsoft handling the replication automatically
Guaranteed low latencyBacked by an SLA — single-digit-millisecond reads and writes at the 99th percentile
Tunable consistencyFive consistency levels to choose from (from Strong down to Eventual), letting an application trade off consistency guarantees against latency and cost per use case
Elastic scaleThroughput (measured in Request Units, or RU/s) and storage scale independently and automatically, without provisioning servers
Fully managed (PaaS)No servers, patching, or cluster management — it's consumed purely as a service

For this project specifically, the API in question is the NoSQL (Core) API — the JSON-document model, which is also the one with built-in vector search support (see Vector Database Capabilities).
