Overview — What is an ORM, and what is Entity Framework Core

Plain An application needs to read and write data in a database. Without help, a developer writes raw SQL for every operation and manually converts each database row into a C# object, and back again. An ORM (Object-Relational Mapper) automates that translation — the developer works with plain C# classes and the ORM generates the SQL underneath.
Technical Entity Framework Core (EF Core) is Microsoft's ORM for .NET. It maps C# classes ("entities") to database tables, tracks changes made to those objects in memory, and generates the corresponding SQL (INSERT/UPDATE/DELETE/ parameterized SELECT) when changes are saved. It supports multiple database providers (SQL Server, PostgreSQL, SQLite, etc.) through a common API, and includes a migrations system for evolving the database schema alongside the codebase.
