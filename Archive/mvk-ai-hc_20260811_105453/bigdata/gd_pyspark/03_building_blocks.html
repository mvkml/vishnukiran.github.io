Building Blocks

Plain This is a genuine, self-hosted Spark environment running on a single machine — not a Databricks subscription. The setup documentation is upfront about that distinction rather than blurring the two together.

From hc_bigdata/document/setup/databricks_local_equivalent.md, stated directly:

"Databricks has no true 'on-premise' version — it is a commercial SaaS platform... What we are actually building is the open-source stack Databricks itself is built on (Apache Spark + notebooks), self-hosted on your laptop."

Databricks conceptLocal equivalent actually used
WorkspaceProject folder (hc_bigdata/)
ClusterLocal SparkSession, master("local[*]")
DBFSLocal disk paths
Delta LakeNot installed — plain CSV reads only

The dedicated Python 3.12 environment exists because the machine's default Python (3.14) isn't yet supported by this PySpark version — a deliberately isolated, reproducible venv avoids that conflict entirely.
