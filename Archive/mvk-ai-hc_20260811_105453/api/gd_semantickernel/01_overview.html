Semantic Kernel / Topic 1

Overview

Plain Semantic Kernel sits between the AI assistant's API layer and the actual language model — it's the piece that knows how to talk to a model, so the rest of the application doesn't need to know the details of any particular AI provider.
Technical Microsoft Semantic Kernel is an open-source SDK for building AI orchestration into .NET applications — a Kernel object wraps a connection to a language model provider behind a common interface. In HC.AI.MAPI, it's the layer that turns a validated prompt into an actual call against Ollama and returns the raw model output.

One thing worth stating up front, covered in full in Design vs. Reality: not every AI-related endpoint in HC.AI.MAPI goes through Semantic Kernel today. The locked, current-generation Doctor endpoint (provide-prompt) does. A couple of earlier, still-present endpoints on the same controller call Ollama directly over HTTP instead, bypassing Semantic Kernel entirely — both paths coexist in the code right now.
