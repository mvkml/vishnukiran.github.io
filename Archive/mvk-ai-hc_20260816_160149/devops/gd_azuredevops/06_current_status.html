Real operational issues hit and fixed while building this automation, kept here rather than smoothed over, since they're genuinely representative of what integrating with this API involves:

  • A PAT generated without explicit Work Items write scope authenticates fine but fails with 401 Unauthorized the moment it tries to create anything — regenerating the token with the correct scope resolved it.
  • Assuming the Agile process template (Epic → Feature → User Story) produced 400 Bad Request on every Feature/User Story creation attempt — resolved by querying _apis/wit/workitemtypes directly and restructuring the plan around the actual Basic template (Epic → Issue).
