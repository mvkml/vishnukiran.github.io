Introduction to SQL

SQL stands for Structured Query Language. It is the standard language used to communicate with relational databases.

SQL helps us create database structures, store records, read information, update existing data, delete data, and control access. In simple words, SQL is how an application talks to a database in an organized and reliable way.

SQL was developed at IBM in the 1970s. Donald D. Chamberlin and Raymond F. Boyce are commonly credited as the original designers of SQL.

SQL Server is Microsoft's relational database system. In this project, SQL Server stores and protects the healthcare data used by the backend APIs.

DDL Defines structure: CREATE, ALTER, DROP.
DML Changes data: INSERT, UPDATE, DELETE.
DQL Reads data: SELECT.
DCL Controls access: GRANT, REVOKE.
TCL Manages transactions: COMMIT, ROLLBACK.
