What Is Model Context Protocol?

Plain MCP is a standard way for an AI assistant to use external tools and data sources. Instead of asking the model to guess, the assistant can call an approved tool, receive real data, and compose an answer from that result.
Technical MCP provides a protocol boundary between an AI client/agent and a server that exposes tools, resources, and prompts. The server describes callable capabilities in a structured form, the client invokes them with typed arguments, and the result is returned to the model workflow as governed context.
