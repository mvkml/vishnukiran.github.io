4. What Is MCP Inspector?

Technical MCP Inspector is an interactive developer tool for testing and debugging MCP servers. It provides a browser UI and CLI mode that can connect to MCP servers, list tools/resources/ prompts, inspect schemas, call tools with custom inputs, and view server messages.
Inspector AreaPurposeWhy It Matters For This Project
Connection paneSelects transport and connection details.Confirms the ASP.NET Core MCP endpoint can be reached.
Tools tabLists available tools, schemas, and tool execution results.Will prove that PatientChart is exposed as a real MCP tool after implementation.
Resources tabShows available resources and metadata.Useful later if the MCP service exposes read-only healthcare resources.
Prompts tabDisplays prompt templates and arguments.Useful later if reusable MCP prompts are added for Doctor or Patient personas.
Notifications/messagesShows server logs and protocol messages.Helps debug tool discovery, bad inputs, and failed calls during development.

5. ASP.NET Core MCP Validation Process

1. Run the ASP.NET Core MCP API locally. 2. Confirm the service starts and exposes the MCP endpoint through app.MapMcp(). 3. Start MCP Inspector with npx. 4. Connect Inspector to the local MCP endpoint using HTTP transport. 5. Open the Tools tab. 6. Confirm the expected MCP tools are listed. 7. Call a tool with valid input and verify the result. 8. Call the same tool with invalid input and verify safe validation errors.
Current status for HC.AI.MCP: the ASP.NET Core host already registers AddMcpServer(), WithHttpTransport(), WithToolsFromAssembly(), and MapMcp(). The REST PatientChart capability exists today. The next validation milestone is to expose PatientChart from HC.AI.MCP.Tools as an MCP tool, then verify it appears and executes inside MCP Inspector.
