Backend for Frontend

Integration PatternPlanned
Plain: A BFF is a backend shaped for one specific consumer, instead of one generic backend for everyone.

What It Is

Backend for Frontend is a specialization of the gateway idea, popularized in microservice architecture. Each client type can have its own backend surface tailored to its workflow.

Why, When, How

Use it when a mobile app, web app, or AI agent needs a different data shape, security scope, or orchestration flow from other consumers.

Why We Chose It Here

The Doctor agent should receive a tool surface designed for doctor workflows. A future Nurse or Admin agent should not automatically inherit the same host list, tool list, or orchestration rules.
