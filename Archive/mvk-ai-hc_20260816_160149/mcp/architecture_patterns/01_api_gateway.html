API Gateway

Integration PatternPlanned
Plain: An API Gateway gives clients one front door instead of making them know every backend service address.

What It Is

An API Gateway is a service entry point that receives client calls and routes them to the right backend service. In microservice literature, it became common as systems moved from monoliths to many independently deployed services.

Why, When, How

Use it when clients should not manage many service URLs, authentication rules, protocol details, retries, or routing decisions. It centralizes cross-cutting concerns while backend services stay independently owned.

Why We Chose It Here

ADR004 splits future MCP tools into separate hosts such as HC.AI.MCP.Patient.OP, HC.AI.MCP.Patient.ICU, and HC.AI.MCP.Patient.Emergency. A gateway can let the Doctor Executor see one controlled MCP-facing entry point while the domain hosts remain segregated behind it.
