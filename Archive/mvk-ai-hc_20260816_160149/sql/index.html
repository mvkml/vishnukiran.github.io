What Is SQL?

SQL stands for Structured Query Language. It is a language used to communicate with relational databases.

SQL is used to store data, read data, update data, delete data, create database objects, and manage database access. In simple words, SQL helps an application talk to the database in an organized way.

SQL was developed at IBM in the 1970s. Donald D. Chamberlin and Raymond F. Boyce are commonly credited as the original designers of SQL.

In a project, SQL helps us define tables, insert records, search data, connect related tables, and prepare data for applications, reports, and APIs.

What Is a Database?

A database is an organized place where application data is stored. Instead of keeping information randomly, a database stores data in tables with rows and columns.

For example, in a healthcare project, a database can store patients, doctors, appointments, prescriptions, roles, permissions, and clinical notes.

Important Database Concepts

Table

A table stores one type of information, such as patients, doctors, or appointments.

Row

A row is one record inside a table, such as one patient record.

Column

A column is one field of data, such as PatientName, DateOfBirth, or PhoneNumber.

Relationship

A relationship connects tables, such as a patient having many appointments.

Types of SQL Commands

DDL

Data Definition Language is used to define database structure. Examples: CREATE, ALTER, DROP, TRUNCATE.

DML

Data Manipulation Language is used to work with table data. Examples: INSERT, UPDATE, DELETE.

DQL

Data Query Language is used to read data from tables. Example: SELECT.

DCL

Data Control Language is used to control access. Examples: GRANT, REVOKE.

TCL

Transaction Control Language is used to manage transactions. Examples: COMMIT, ROLLBACK, SAVEPOINT.
