API Documentation

Plain Every API can be explored and tried out directly in a browser, without needing a separate tool or written spec — the documentation is generated from the code itself, so it can't silently drift out of date the way a hand-written doc can.

Swagger/OpenAPI is enabled (in development) on all four APIs, generated automatically from the controllers and their attributes:

APISwagger UI (local dev)Notes
HC.AI.Identity.Apihttp://localhost:5008/swagger—
HC.AI.MAPIhttp://localhost:5150/swaggerEnriched with XML doc comments for richer descriptions; auto-opens on launch
AI.HealthCare.Patient.APIhttp://localhost:5295/swaggerAvailable, but doesn't auto-open on launch
HC.AI.Admin.APIhttp://localhost:5097/swaggerAvailable, no auto-launch configured

Only HC.AI.MAPI currently goes further than the default and includes XML documentation comments (IncludeXmlComments), giving its Swagger page richer, human-written descriptions per endpoint — the other three rely on Swagger's default reflection-based output.
