The One Real End-to-End LLM Test

Plain Most tests avoid depending on things as slow and variable as a live language model. This suite has exactly one test that doesn't avoid it — and does so on purpose, with the other two related tests deliberately kept fast by mocking the network instead.

patient-chat.spec.ts — the real case:

test('sending a message returns a real reply from the patient executor model', async ({ page, baseURL }) => { test.setTimeout(120_000); await loginAsPatient(page, baseURL); await page.locator('textarea').fill('hi'); await page.getByRole('button', { name: /send/i }).click(); // Real Ollama generation — the composer's own status line warns this can take up to ~30s. await expect(page.getByText(/hc-patient-executor/)).toBeVisible({ timeout: 110_000 }); });

This test genuinely logs in, sends a real message, and waits — up to nearly two minutes — for a real reply generated by the hc-patient-executor Ollama model, then asserts the model name actually shows up in the UI. It's the closest thing in this codebase to a true smoke test of the entire stack: Angular → Identity API → MAPI → Semantic Kernel → Ollama → back to the screen.

The file's own header comment explains the design choice directly: one real end-to-end case, plus two fast, network-mocked cases for the error paths (a dropped-request banner and a validation-error banner), "so this suite doesn't pay the ~5-90s real-generation cost more than once."
