Fan-Out / Fan-In Agent Pattern

Runs multiple specialist agents for one request and merges the results into one response.

Purpose: avoid making one large agent responsible for every healthcare domain. Each specialist handles its own domain, while the system combines results for the doctor.

How It Works

PhaseDescription

Wait and collectCollect structured responses, status, evidence, and errors.
Fan-inMerge all domain outputs into one concise doctor-facing answer.

Healthcare Example

The system can retrieve appointment, medication, insurance, and lab data in parallel after the patient identity is known.
