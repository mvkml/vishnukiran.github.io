AI Agents

How Healthcare Co-Pilot Studio will use agents to plan, call tools, retrieve governed context, and complete healthcare workflows safely.

Architecture Draft LangChain Semantic Kernel
Executive summary: an agent is an AI workflow component that can reason over a goal, choose tools, call those tools, evaluate results, and continue until it can return a useful answer or action. In this platform, agents must work through controlled healthcare boundaries such as MCP tools, identity, persona rules, validation, and audit-friendly APIs.
